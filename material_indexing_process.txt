Material Indexing Process
=========================

Changes made:
- Added material_documents and material_chunks SQLAlchemy tables.
- Added college, semester, and regulation metadata fields and indexes.
- Added Pydantic schemas for material documents, chunks, scopes, and search requests.
- Added parsing support for TXT, Markdown, RST, PDF, and DOCX files.
- Added text cleaning and overlapping chunk generation.
- Added SHA-256 file hashing and MIME type detection.
- Added local Sentence Transformers model: all-MiniLM-L6-v2.
- Added persistent ChromaDB collection: college_materials.
- Added metadata pre-filtering by college, semester, and regulation.
- Added CHROMA_PATH configuration with default path ./.chroma.
